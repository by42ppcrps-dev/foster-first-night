    How it works

    1. Qloo knows taste. Each favorite is looked up in Qloo. Its recommendations, tags and explainability scores supply every title, artist and restaurant. Nothing is invented.
    2. An agent plans. A Gemini model chooses which tools to call and words the openers and the evening. It sees only what you typed after the privacy screen.
    3. Code has the last word. Content ratings for the child’s age, trigger words, themes like separation or adoption, explicit music and adult venues are enforced in code. The agent cannot override them, and every item held back is listed with its reason.

    For agents

    The same planner and safety layer is a Model Context Protocol server over Streamable HTTP. Any MCP client can plan a first night or check one title.
